# Legacy Python Chess Engine (Middle School Archive)

*Note: This is a personal archive project. For my current work please check my other repositories.*

This repository contains a fully functional chess engine I built from scratch in Python during 6th and 7th grade, with a few minor tweaks added in my first year of high school. 

### Technical Overview
* Includes a custom-built move generator, rule validation (check/mate/stalemate), and a terminal-based UI.
* The AI relies on a basic brute-force game tree search (hardcoded to `depth=2`) and a simple heuristic evaluation function based on material and controlled squares.

### Why is this public?
While this code doesn't use modern engine optimizations like bitboards, alpha-beta pruning, or clean architectural patterns, I keep it public as a personal milestone. Building this was my first deep dive into algorithmic decision-making and Python programming. It marks the exact origin of my passion for artificial intelligence, long before I transitioned to competitive C++ programming and building production-grade LLM architectures.
